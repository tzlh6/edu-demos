分布系数曲线怎么读

第 15 题常温下 H2A 溶液中各粒子分布系数 δ 与 −lg c(OH−) 的关系。拖动滑块，看三种粒子此消彼长。

一、拖动：c(OH−) 变小，酸性变强

−lg c(OH−) = 7.00pH = 7.00
δ(H2A)0.50
δ(HA−)0.50
δ(A2−)0.00

横轴从左到右 −lg c(OH−) 减小 → c(OH−) 增大 → 碱性增强。所以从左到右依次是 H2A 占优、HA− 占优、A2− 占优：曲线①是 δ(H2A)，②是 δ(HA−)，③是 δ(A2−)。

二、交点为什么就是 Ka

在 ①② 交点，δ(H2A) = δ(HA−)，即 c(H2A) = c(HA−)，代入
Ka1 = c(H+)·c(HA−) ⁄ c(H2A) = c(H+)。
交点处 −lg c(OH−) = 7，pH = 7，所以 Ka1 = 10−7；同理 ②③ 交点 pH = 13，Ka2 = 10−13。
C 项：K 怎么化成已知常数？

MA + 2H+ ⇌ M2+ + H2A，K = c(M2+)·c(H2A) ⁄ c2(H+)。分子分母同乘 c(A2−)·c(HA−)，就拆成
K = Ksp(MA) ⁄ (Ka1·Ka2) = 10−26 ⁄ (10−7×10−13) = 10−6，不是 106。

三、Na2A 溶液：谁的浓度大

c(Na2A) = 0.010 mol·L−1　Kh1 = Kw ⁄ Ka2 = 0.1

A2− + H2O ⇌ HA− + OH− 的 Kh1 很大，A2− 大部分水解；HA− 再水解（Kh2 = 10−7）又补充少量 OH−，所以始终 c(Na+) > c(OH−) > c(HA−) > c(A2−)。（条形长度按对数比例画。）
