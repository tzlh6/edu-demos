# 猪猪游乐场 4.2

双击 `../../03_成品/猪猪游乐场-4.2-Win7兼容.exe` 即可游玩，或直接打开 `../../03_成品/猪猪游乐场v4.2.html`：图片、规则、音效全部内嵌，断网可用。4.1 及更早版本的成品、源文件与说明保留在各自的历史目录。

## 4.2 更新（2026-10-10）

共 18 款。新增第 18 款「猪猪轮盘」，全部猪猪换上新造型，整体界面与操作反馈重新整理，所有游戏都能只用鼠标单击或触屏点按玩完，并新增一整套合成猪叫。

### 猪猪轮盘（id = roulette）

暗黑童话舞台：昏暗木桌、暖色吊灯聚光、紫色阴影；两侧是两只猪，中间是一把猪猪造型的枪（猪鼻子是枪口，透明的“枪肚子”里装着屎弹）。游乐场外框仍是明亮软萌的，只有轮盘舞台是暗色。

- 对战：离线 AI（悠闲 / 聪明 / 恶魔，默认聪明）与同屏双人；三局两胜，每局每只猪 4 滴血。第一局随机先手，之后交替；新局重置血量、道具、线索、泥巴与强化。
- 弹药：每批 2–8 发、真假至少各一，数量公开、顺序隐藏，装填时只洗牌一次。真屎棕色带“真”字与纹路，假屎灰紫色带圆点与“假”字；未公开的弹药外观完全相同。
- 开枪：对自己打出假屎不扣血、继续行动；打出真屎扣血并结束回合；对对手开枪无论真假都结束回合。真屎通常伤害 1，强化后 2，对自己同样有效。弹药耗尽时先按刚才的行动确定回合归属，再重新装填；每次装填双方各随机补两件道具（六种等概率，背包最多八件，按空位补）。
- 六件道具都不结束回合：魔法书（变身魔法猪，公开下一发）、X 光（任选剩余位置扫描）、饲料（放屁压缩共用的猪猪枪，下一发真正射出的真屎 ×2；跟着枪走，对手也能用，假屎 / 退弹 / 重新装填都不消耗，不可叠加）、肉（回 1 滴血，满血不能用）、泥巴（跳过对手下一次本应获得的回合；不能叠加，每批弹药每只猪最多一次）、马桶搋子（吸出当前一发并公开；吸出最后一发时重新装填，强化保留）。已公开的位置不会重复消耗查弹道具，非法行动不消耗物品、不改变任何状态，并在界面上说明原因。
- 公开信息：双方背包、已公开位置（随弹药消耗前移，重新装填清空）、强化与泥巴状态双方都看得见；界面会按剩余真假数量提示“下一发是真屎的机会”。
- 演出：每件道具约 2.5 秒、饲料约 3 秒，按“预备 → 动作 → 关键时刻生效 → 收势”编排，镜头推近、黑边、表情、身体弹性和音效在关键帧同步（魔法书翻页变身、X 光扫描显影、饲料咀嚼放屁压缩、肉抱啃吞咽回血、泥巴弧线黏脚挣扎、搋子贴合拉伸“啵”出）。开枪有举枪、转向、心跳停顿、发射、真屎飞溅后仰或假屎“噗”的滑稽反应。工具栏可改“轻快”节奏，默认电影感。
- 生命周期：演出期间锁定对局输入；暂停冻结时间轴，恢复后从原位置继续；换装不丢本局；重开 / 换游戏换一套新状态，旧演出、旧音效和待执行任务全部作废，不会重复扣血或消耗道具。遵守“减少动态效果”：去掉镜头运动和震动，保留结果与反馈。
- AI 只读取公开局面（`publicView`），拿不到隐藏队列和随机种子；恶魔档在公开信息上做小型期望搜索。
- 操作：点背包里的道具、点中间的“对自己开枪 / 对对手开枪”；用 X 光时再点一个未知位置。键盘：Z 对自己、X 对对手、1–8 道具、Esc 取消，R 重开整场。

规则在 `app/roulette-core.js`（可注入随机源，返回可播放事件），舞台美术在 `app/roulette-art.js`，时间轴、动画与界面在 `app/roulette-ui.js`。

### 全部猪猪的新造型

参考 [PigHub](https://pighub.top/) 的比例与气质重新绘制：侧身朝左、桃粉大肚子、极短的粗腿、弯卷的耳朵、卷尾巴、短鼻子和小黑眼睛。只观察比例与气质，没有使用站内图片或表情包。

- 唯一可编辑来源是 `app/pig-art.js`：身体轮廓是一组关键点（自动生成圆润曲线），耳、腿、眼、尾、身体、头、道具各自一组，可以分层摆姿势（`PigArt.Rig`），有 11 种表情（开心、惊讶、晕、哭、得意、咀嚼等）。
- `node make-pigs.cjs` 重新生成 4 种配色 × 13 套（基础猪 + 12 套服饰）= 52 个造型文件、12 张卡片、默认头像和消消乐 6 种棋子；资源键与 4.1 完全相同，存档与换装兼容。`make-pigs.py` / `make-match-pigs.py` 保留为兼容入口。
- 卡片、主角、2048 成长图鉴、棋子、预览、暂停与结果页同步换新；游戏画面里的精灵使用同一造型的透明底版本。消消乐六种棋子仍以颜色、服饰和形状角标区分。

### 只用鼠标 / 触屏就能玩

每款游戏都有屏幕按钮（最小 44 px 触控高度）。跳跳猪单击“趴下”会低头约 0.65 秒；切切猪点一下也能切中；星际守卫点哪飞哪（平滑移动，不瞬移）；节奏派对默认“单击模式”：长条点一下自动保持到尾端，双键只要点其中一个（可关闭恢复挑战模式）。

### 合成猪叫库

`app/audio.js` 新增本地合成的猪叫：轻快哼哼、咯咯笑、哼唧、得意一哼、嫌弃喷鼻、惊叫、哎哟、委屈呜咽、受击哀嚎、打呼噜、欢呼。走“猪叫”音量层，跟随三种音色，同时最多四只，暂停 / 静音 / 切换游戏一并停止。用在轮盘的受击、假屎、泥巴、饲料、回血、胜负，以及其他游戏的撞墙、失误、点错、连击等时刻；声音工坊里可以单独试听。点主视觉里的小猪也会哼一声。

### 界面

统一为奶油底 + 糖果粉 + 鼠尾草绿：侧栏游戏图标分色、当前游戏高亮条、带图标的搜索框；按钮统一的悬停、按下、键盘焦点与禁用状态；无效操作会在消息条里显示原因（橙色提示，轻微晃动），成功用绿色提示；暂停时小猪睡觉，结果页小猪按胜负换表情；换装窗口可预览服饰。

## 4.1 更新（2026-10-10）

新增三款挑战游戏，共 17 款，并重做消消乐的表现与规则。本轮先阅读下文所列 GitHub 仓库的具体实现和许可证，再结合本项目的离线运行、猪猪造型、声音与公共暂停机制改写。

| 游戏 | 新玩法 |
|---|---|
| 切切猪 | 按住鼠标或手指划切飞起的软糖猪，一划多只可连切加分；金猪加分、冰猪减速，避开黑刺球。经典三次失误、60 秒冲分、高手密集出场三档；空格配合方向键 / WASD 也可操控光刃 |

消消乐使用六个独立原创 SVG：红蝴蝶结、金皇冠、绿叶、蓝潜水、紫魔法、橙小虎。身体、服饰、格子底色和形状角标共同区分，不随全局换装被统一染成一种颜色。入门档使用五种，后两档使用全部六种。`make-match-pigs.py` 可以重建这些矢量文件。

- 横向四连留下横火箭，竖向四连留下竖火箭，分别清整行 / 整列。
- T / L 交叉留下爆爆猪，清周围 3×3；五连留下彩虹猪，与普通猪交换时清掉同色猪。
- 特殊猪与相邻猪交换即可发动。双火箭清十字；火箭 + 爆爆猪清三行三列；双爆爆猪清 5×5；彩虹 + 特殊猪把该颜色转换成对应特殊猪并发动；双彩虹全屏清场。
- 无效交换不扣步数。无路重排保留特殊猪、冰层与目标进度。单层 / 双层冰每次命中消去一层，过关必须同时达成得分、破冰与收集目标。

切割、火箭、爆爆猪、彩虹、星光射击、清弹护盾、节拍与判定都有不同的合成音效，继续使用声音工坊的三种音色。小动作保持轻声，连切与重要事件搭配猪叫。节奏派对使用音频时钟推进谱面，暂停后重新对齐时钟，不追赶暂停期间的时间；旋律和谱面均为本项目创作。

## 开发与重建

安装 Node.js 与 npm，在本目录运行：

```text
npm install
npm test                      # 六个规则 / 音效测试（含 test-roulette.cjs）
node make-pigs.cjs            # 改了 app/pig-art.js 后重新生成全部猪猪矢量
npx electron .
npx electron-builder --win portable --ia32 --publish never
python build-single.py ../../03_成品/猪猪游乐场v4.2.html
node tools/playtest-click.cjs # 可选：需要 Playwright，只用鼠标试玩 18 款
```

桌面构建输出为 `dist/猪猪游乐场-4.2-Win7兼容.exe`。本次同时交付便携桌面程序与单文件网页版。构建工作目录为 `99_工作文件/猪猪游乐场/桌面构建_20261009/`，可编辑源目录未加入构建依赖或解包缓存。

为兼容 Windows 7，Electron 固定为 22.3.27（最后一个支持 Win7/8/8.1 的版本，内核 Chromium 108），并打包为 32 位（ia32），这样 32 位和 64 位的 Win7–Win11 都能运行。不要把 Electron 升到 23 及以上，否则 Win7 无法启动。前端代码避开了 Chromium 108 不支持的写法（CSS 嵌套、color-mix、:has 等），所有图标改为内嵌 SVG，不依赖 Win7 缺失的彩色 emoji 字体。

`build/afterPack.cjs` 用 resedit（纯 JS，不需要 Wine）把猪头图标和中文版本信息写进程序。`pnpm-lock.yaml` 是 2.1 版（Electron 44）留下的，已不适用，请以 `package-lock.json` 为准。

## 文件结构

- app/core.js：扫猪、2048、贪吃猪、跳跳猪规则（4.2：跳跳猪单击也能跳过最高障碍的最低跳高）。
- app/roulette-core.js：猪猪轮盘唯一的规则状态、装填、道具、三局两胜计分、公开局面与三档 AI（可注入随机源）。
- app/roulette-art.js / app/roulette-ui.js：轮盘暗黑童话舞台美术；演出时间轴、镜头、道具动画、音效关键帧、操作界面与生命周期。
- app/pig-art.js：全部猪猪造型的唯一可编辑来源（关键点轮廓、四配色、十二服饰、消消乐六棋子、表情、分层姿势 Rig）。make-pigs.cjs 由它生成 app/assets 下的矢量文件。
- app/look.js：配色切换与存档；卡片版造型（assets/skins）与游戏画面用的透明精灵。
- app/audio.js：分层音效引擎（Web Audio）；4.2 新增合成猪叫库与轮盘音效。app/sounds.js：四段录音猪叫。
- app/arcade-core.js / arcade.js、match-core.js / match-ui.js、challenge-core.js / challenge.js：4.0 / 4.1 各游戏规则与画面（4.2：节奏派对单击模式、切切猪点按切、星际守卫点哪飞哪、弹弹猪单击挪板）。

## 声音设计

| 层次 | 什么时候 | 声音 |
|---|---|---|
| 轻 | 翻格、数字、标旗/取消、连开、翻牌、滑动、撤销、地鼠探头、倒计时、贪吃猪转向、跳跃落地、吃苹果 | 合成提示音：数字 1–8 音高逐级升高；连开按翻开格数奏上行琶音 |
| 中 | 配对成功、2048 每次合成、抓到小猪、吃松露、二段跳、每满 100 分 | 单声猪叫：每种卡面小猪固定一个声音；连续配对、连击越多音调越高；2048 每次合成先“啵”一声再哼，小猪越大叫声越长越低（小猪仔短促尖叫 → 猪猪国王低沉一声 + 和弦），一步合成多对时依次错开 |
| 重 | 踩到猪、撞墙/绊倒、胜利 | 踩到猪：猪爸爸低沉一声 + 爆炸，其余小猪从踩中处向外依次炸醒（约 4 秒内全部醒来），左右声道按列分布，最多 10 声同时叠响；胜利：琶音 + 四只猪轮流再齐声 |

声音工坊里有主音量、猪叫、提示音三个滑杆，可以试听四只猪、连环炸猪和胜利合唱。

## 3.1 更新

- 猪猪 2048：数字换成 13 种小猪（2 小猪仔 → 4 蝴蝶结猪 → 8 花环猪 → 16 蜜蜂猪 → 32 围巾猪 → 64 耳机猪 → 128 眼镜猪 → 256 厨师猪 → 512 侦探猪 → 1024 海盗猪 → 2048 猪猪国王 → 4096 魔法猪 → 8192 太空猪）；小猪会滑动、合成时放大弹出；右侧成长图鉴记录见过的最大小猪；每次合成都有“啵 + 哼”音效。
- 新游戏「贪吃猪」：经典贪吃蛇，猪妈妈带着猪仔队伍吃松露，每 5 颗出现限时金松露；三档速度，越吃越快。
