## 4.1 更新（2026-10-10）

新增三款挑战游戏，共 17 款，并重做消消乐的表现与规则。本轮先阅读下文所列 GitHub 仓库的具体实现和许可证，再结合本项目的离线运行、猪猪造型、声音与公共暂停机制改写。

| 游戏 | 新玩法 |
|---|---|
| 切切猪 | 按住鼠标或手指划切飞起的软糖猪，一划多只可连切加分；金猪加分、冰猪减速，避开黑刺球。经典三次失误、60 秒冲分、高手密集出场三档；空格配合方向键 / WASD 也可操控光刃 |
| 猪猪星际守卫 | 自动射击、六像素主角判定点、擦弹加分、Shift 慢移、九秒恢复的清弹护盾、补血星星；挑战三位随血量变换扇形 / 环形 / 瞄准弹的首领 |
| 猪猪节奏派对 | 原创合成旋律与四轨谱面；D F J K 或方向键 / 屏幕按钮，单点、长按和双键；104 / 124 / 148 BPM 三档，完美 / 准确 / 漏拍、连击、体力与准确率，支持判定偏移 |
| 猪猪消消乐 | 真正的交换滑动、无效交换滑回、消除、生成特殊猪、连续掉落与连锁动画；破冰和指定猪收集目标 |

消消乐使用六个独立原创 SVG：红蝴蝶结、金皇冠、绿叶、蓝潜水、紫魔法、橙小虎。身体、服饰、格子底色和形状角标共同区分，不随全局换装被统一染成一种颜色。入门档使用五种，后两档使用全部六种。`make-match-pigs.py` 可以重建这些矢量文件。

- 横向四连留下横火箭，竖向四连留下竖火箭，分别清整行 / 整列。
- T / L 交叉留下爆爆猪，清周围 3×3；五连留下彩虹猪，与普通猪交换时清掉同色猪。
- 特殊猪与相邻猪交换即可发动。双火箭清十字；火箭 + 爆爆猪清三行三列；双爆爆猪清 5×5；彩虹 + 特殊猪把该颜色转换成对应特殊猪并发动；双彩虹全屏清场。
- 无效交换不扣步数。无路重排保留特殊猪、冰层与目标进度。单层 / 双层冰每次命中消去一层，过关必须同时达成得分、破冰与收集目标。

切割、火箭、爆爆猪、彩虹、星光射击、清弹护盾、节拍与判定都有不同的合成音效，继续使用声音工坊的三种音色。小动作保持轻声，连切与重要事件搭配猪叫。节奏派对使用音频时钟推进谱面，暂停后重新对齐时钟，不追赶暂停期间的时间；旋律和谱面均为本项目创作。

猪猪形象按 [PigHub](https://pighub.top/) 的圆滚滚、短腿、卷尾、呆萌气质原创绘制，没有复制站内图片。提供奶桃团子、草莓糯米、奶油布丁、芋泥啵啵四种配色，每种包含基础猪和 12 套服饰，共 52 个 SVG。点击右上角“猪猪换装”切换；棋子、卡片、合成图鉴和画面里的主角一起换装，本局进度保留。`make-pigs.py` 可重建全部矢量文件。

侧栏可滚动、可搜索；窄屏改为横向游戏导航。打开设置或切出窗口自动暂停，关闭设置后点击“继续”恢复。切换游戏和难度会开始新局。成绩、配色和音色按当前浏览器来源保存；不同浏览器或不同文件地址未必共享存档。

## 开发与重建

安装 Node.js 与 npm，在本目录运行：

```text
npm install
node test.cjs
node test-sound.cjs
node test-arcade.cjs
node test-new-games.cjs
node test-challenge.cjs
npx electron .
npx electron-builder --win portable --ia32 --publish never
python build-single.py ../../03_成品/猪猪游乐场v4.1.html
```

桌面构建输出为 `dist/猪猪游乐场-4.1-Win7兼容.exe`。本次同时交付便携桌面程序与单文件网页版。构建工作目录为 `99_工作文件/猪猪游乐场/桌面构建_20261009/`，可编辑源目录未加入构建依赖或解包缓存。

为兼容 Windows 7，Electron 固定为 22.3.27（最后一个支持 Win7/8/8.1 的版本，内核 Chromium 108），并打包为 32 位（ia32），这样 32 位和 64 位的 Win7–Win11 都能运行。不要把 Electron 升到 23 及以上，否则 Win7 无法启动。前端代码避开了 Chromium 108 不支持的写法（CSS 嵌套、color-mix、:has 等），所有图标改为内嵌 SVG，不依赖 Win7 缺失的彩色 emoji 字体。

`build/afterPack.cjs` 用 resedit（纯 JS，不需要 Wine）把猪头图标和中文版本信息写进程序。`pnpm-lock.yaml` 是 2.1 版（Electron 44）留下的，已不适用，请以 `package-lock.json` 为准。

## 文件结构

- app/core.js：纯游戏规则——扫猪（胜利自动标旗、失败后小猪苏醒顺序）、2048（含每只小猪的移动轨迹）、贪吃猪 Snake、跳跳猪 Runner。
- app/audio.js：分层音效引擎（Web Audio）。
- app/sounds.js：四段猪叫（base64 内嵌，离线、file:// 下都能解码）。app/assets/voice0–3.mp3 是同样的录音，便于单独试听或替换。
- app/arcade-core.js：4.0 新增游戏的规则、四子棋对手、点灯与推箱子求解器；消消乐规则从 match-core.js 引入。
- app/match-core.js / app/match-ui.js：消消乐的匹配、特殊猪组合、破冰 / 收集、独立编号与分阶段动画。
- app/challenge-core.js / app/challenge.js：切割、弹幕、节奏的独立规则、画面、操作和音频时钟。
- app/arcade.js：新增游戏的画面、操作、暂停、成绩和结果。
- app/look.js / app/assets/skins/：四种配色和全部 SVG；make-pigs.py 为可编辑的生成入口。
- app/app.js：原有六款游戏与公共界面，将全部 17 款接入暂停、成绩、结果浮层和声音。
- app/style.css：界面与动效；矮屏（≤900 px 高）自动收起顶部插画，扫猪格子按窗口自适应。
- main.cjs：离线 Electron 入口，禁用远程请求与新窗口，允许无手势播放声音。
- test.cjs / test-sound.cjs / test-arcade.cjs / test-new-games.cjs / test-challenge.cjs：原有与新增游戏规则、特殊猪组合与动画快照、切割 / 弹幕 / 节奏规则、音色及停止 / 静音检查。
- build-single.py：打包单文件网页版。

## 声音设计

| 层次 | 什么时候 | 声音 |
|---|---|---|
| 轻 | 翻格、数字、标旗/取消、连开、翻牌、滑动、撤销、地鼠探头、倒计时、贪吃猪转向、跳跃落地、吃苹果 | 合成提示音：数字 1–8 音高逐级升高；连开按翻开格数奏上行琶音 |
| 中 | 配对成功、2048 每次合成、抓到小猪、吃松露、二段跳、每满 100 分 | 单声猪叫：每种卡面小猪固定一个声音；连续配对、连击越多音调越高；2048 每次合成先“啵”一声再哼，小猪越大叫声越长越低（小猪仔短促尖叫 → 猪猪国王低沉一声 + 和弦），一步合成多对时依次错开 |
| 重 | 踩到猪、撞墙/绊倒、胜利 | 踩到猪：猪爸爸低沉一声 + 爆炸，其余小猪从踩中处向外依次炸醒（约 4 秒内全部醒来），左右声道按列分布，最多 10 声同时叠响；胜利：琶音 + 四只猪轮流再齐声 |

声音工坊里有主音量、猪叫、提示音三个滑杆，可以试听四只猪、连环炸猪和胜利合唱。

## 3.1 更新

- 猪猪 2048：数字换成 13 种小猪（2 小猪仔 → 4 蝴蝶结猪 → 8 花环猪 → 16 蜜蜂猪 → 32 围巾猪 → 64 耳机猪 → 128 眼镜猪 → 256 厨师猪 → 512 侦探猪 → 1024 海盗猪 → 2048 猪猪国王 → 4096 魔法猪 → 8192 太空猪）；小猪会滑动、合成时放大弹出；右侧成长图鉴记录见过的最大小猪；每次合成都有“啵 + 哼”音效。
- 新游戏「贪吃猪」：经典贪吃蛇，猪妈妈带着猪仔队伍吃松露，每 5 颗出现限时金松露；三档速度，越吃越快。
- 新游戏「跳跳猪」：类 Chrome 小恐龙的无尽跑酷，跳篱笆和泥坑、趴下躲乌鸦、吃苹果，可二段跳，越跑越快。用自动玩家模拟 30 局、每局 4 分钟都能一直跑下去，说明不会出现跳不过去的障碍组合。
